# C++ Practical: Data Types, Constants, Variables, Operators, and I/O

## Aim
To write a C++ program demonstrating basic data types, variables, constants, operators, and input/output statements.

## Concepts demonstrated
- Data types: `string`, `int`, `double`, `char`, and `bool`
- Variables: `name`, `age`, `num1`, `num2`, `grade`, and `isStudent`
- Constant: `PI`, declared with `const`
- Arithmetic operators: `+`, `-`, `*`, `/`
- Relational operators: `>=`, `>`, `!=`
- Logical operator: `&&`
- Input/output: `cin`, `getline()`, and `cout`

## Compile and run

Install a C++ compiler such as g++.

```bash
g++ -std=c++17 main.cpp -o practical
./practical
```

On Windows, run `practical.exe` after compilation.

## Sample input

```text
Alex
20
12 4
A
```
